# 故障排查

## 14:50 没有提醒

依次检查：

1. 当天是否为 A 股交易日；
2. 电脑在14:45—15:00是否处于唤醒状态；
3. 网络是否可用；
4. 系统调度任务是否启用；
5. 行情时间是否超过10分钟；
6. 是否已经在本周成功发送过该基金的额外投入提醒；
7. 通知渠道是否缺少凭证。

## `MISSED_EXECUTION_WINDOW`

任务在15:00后才启动。系统会记录异常，不使用盘后数据冒充14:50提醒。

## 行情接口失败

AKShare依赖公开接口，接口变动时可能需要升级适配器。系统不会用旧行情生成提醒。

## 导入失败

- 先执行 `validate-backup`；
- 检查迁移包是否被修改；
- 检查磁盘空间；
- 未来版本的数据库不能导入旧版本应用；
- 导入失败后使用 `.pre_import_*.sqlite` 回滚副本。
