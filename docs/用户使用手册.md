# ETF 投资助手用户使用手册

> 适用版本：2026-07-20 本地桌面版
> 适用系统：macOS（Windows 版的主要功能和操作相同）

## 1. 软件用途

ETF 投资助手是一款仅在本机运行的定投与回撤提醒工具。它根据场内 ETF 行情，计算最近 20 个交易日内的累计回撤，并按照你为对应场外联接基金设置的规则生成投入提醒。

软件只提供计划和提醒，不会登录基金、支付宝或券商账户，也不会自动买入。

## 2. 重要概念

- **场内 ETF（信号基金）**：用于查询实时价格、历史 K 线和计算回撤，例如 `159516`。
- **场外联接基金（购买基金）**：你实际定投或补仓的基金，例如 `019632`。
- **基础投资额**：一次固定定投的金额，也是计算额外补仓金额的基数。
- **常规计划**：到设定的星期几时，生成固定定投提醒。
- **回撤提醒**：达到策略档位时，生成额外补仓提醒。

场内 ETF 行情只用于计算信号，不等同于场外联接基金当天最终净值。

## 3. 安装和启动

### 3.1 当前本机版本

应用安装位置：

```text
/Applications/ETF Plan Assistant.app
```

双击“ETF Plan Assistant”即可启动。

### 3.2 首次打开被 macOS 阻止

当前安装包未进行 Apple Developer ID 签名和公证。如果 macOS 阻止启动：

1. 打开“系统设置”；
2. 进入“隐私与安全性”；
3. 找到 ETF Plan Assistant 的拦截提示；
4. 点击“仍要打开”；
5. 再次确认启动。

### 3.3 自动检查的运行条件

每天 14:50 自动检查时，需要满足：

- 当天为 A 股交易日；
- 当前用户保持登录；
- 电脑保持唤醒并连接网络；
- 可以锁屏，但不能进入睡眠；
- 本机的 14:50 调度任务已安装并启用。macOS 安装版首次启动或更新后会自动安装、校正任务。

## 4. 仪表盘

启动后默认进入“市场概览”。

### 4.1 顶部状态

- **本地服务正常**：应用界面和本地数据服务已启动。
- **定时检查：14:50 已启用**：后台任务已注册；如果显示“未启用”，当天不会自动查询。
- **上次检查**：最近一次自动或手动检查的时间和成功、部分失败或失败状态。
- **每周计划**：已开启常规计划的基础金额合计。

### 4.2 三个概览卡片

- **启用监控计划**：当前正在管理的基金计划数量。
- **待处理提醒**：已由策略生成、尚未处理的提醒数量。
- **每周基础投入**：开启固定定投后，每周预计投入的基础金额。

### 4.3 今日触发提醒

发生定投或回撤触发后，会显示基金、当前预计回撤和本次计划金额。

- 先在策略历史表格中选择一条记录，再点击“标记已执行”；保存后该行立即显示“已执行”。如果未选择、已经执行或选中的是 0 元风险提示，软件会给出明确提示。
- 点击“忽略”：本次提醒不再处理。

这些操作只修改本地记录，不会执行真实交易。

如果同一周已经发送过补仓建议，之后又进入更深警戒档，软件仍会发送“风险升级”邮件，但明确显示“本周不重复补仓”。这类 0 元风险提示不能标记为已执行。

## 5. 立即检查

点击仪表盘右侧的“立即检查”后，软件会在后台执行一次完整检查：

1. 查询每只场内 ETF 的最新价格；
2. 查询最近的历史交易日数据；
3. 更新仪表盘价格、涨跌和 20 日回撤；
4. 按当前策略判断是否触发档位；
5. 生成符合条件的历史事件；
6. 通过已开启的桌面通知和邮件渠道发送提醒。

**注意：“立即检查”不是单纯刷新页面，也不是模拟测试。它可能生成真实提醒并发送邮件。**

检查期间按钮会显示“后台抓取中”。请等待本轮结束，不需要重复点击。行情接口响应速度不同，一轮查询通常需要一些时间，但界面仍可正常操作。

## 6. 回撤的计算口径

软件不采用网页已经计算好的回撤结果，而是在本机按以下步骤计算：

1. 获取最近 20 个已完成交易日的收盘价；
2. 取其中最高收盘价计算“短期 20 日回撤”；
3. 尚无活动周期时，短期回撤用于发现第一次触发；
4. 第一次触发补仓档位时，软件把当时的 20 日最高价锁定为本轮固定高点 `cycle_peak`；
5. 本轮所有后续档位和恢复判断均相对固定的 `cycle_peak` 计算。

```text
短期回撤 =（20 日最高收盘价 - 当前最新价）÷ 20 日最高收盘价 × 100%
本轮回撤 =（cycle_peak - 当前最新价）÷ cycle_peak × 100%
```

例如第一次触发时 20 日最高收盘价为 `1.000`，则本轮 `cycle_peak` 固定为 `1.000`。即使长期下跌后滚动 20 日最高价降至 `0.850`，最新价 `0.800` 的本轮回撤仍按 `1.000` 计算为 `20%`，不会错误缩小为 `5.88%`。

### 6.1 分红、拆分和折算处理

- 历史行情优先使用前复权价格，使历史价格与当前价格处于可比较口径。
- 主行情源不可用时，备用行情会识别常见的拆分、合并和折算比例，并调整早期 K 线。
- 如果仍存在无法可靠解释的巨大价格断层，软件会停止该基金本轮回撤判断并提示历史行情不可用，不会使用可疑数据发送补仓提醒。

因此，页面提供的是原始行情来源，短期回撤、本轮固定锚点回撤和触发档位均由本机计算。

### 6.2 盘中估算

14:50 和立即检查取得的是接口返回的最新成交价，不一定是当天最终收盘价。提醒属于盘中估算，软件不会在收盘后自动回滚已经生成的事件。

## 7. 基金管理

点击左侧“基金管理”进入计划列表。

### 7.1 开关计划

每只基金有两个独立开关：

- **常规计划**：控制固定定投提醒；
- **回撤提醒**：控制回撤补仓提醒。

可以只开启其中一项。例如关闭常规计划、保留回撤提醒时，软件不会提示固定定投，但仍会监控回撤。

### 7.2 添加新计划

点击“添加新计划”，填写：

- 计划名称；
- 场外基金代码和名称；
- 场内 ETF 代码和名称；
- 基础投资额；
- 每周固定定投日；
- 常规计划和回撤提醒开关；
- 回撤档位、买入乘数和执行模式。
- 持续补仓的最大执行周数、累计倍数上限和可选金额上限。

基金代码必须为 6 位数字，基础金额必须大于 0。

### 7.3 编辑策略

点击基金右侧“编辑”，可修改计划和回撤阶梯。

添加或编辑计划时可以选择策略初始化模板：

| 模板 | 回撤档位 | 适用方向 |
|---|---|---|
| 稳健 / 低波 | 3%、5%、8%、12%、18% | 红利、低波 |
| 核心宽基 | 4%、7%、10%、15%、22% | A500、沪深 300 等 |
| 高波宽基 | 5%、9%、14%、20%、28% | 创业板、科创、纳指 |
| 行业主题 | 6%、11%、17%、25%、35% | 半导体、创新药、养殖 |
| 完全自定义 | 用户填写 | 其他资产 |

模板只负责填写初始档位。保存后仍是该基金自己的独立策略，模板后续变化不会覆盖已保存内容。

例如基础投资额为 600 元，进入 10% 档且倍数为 2 时，额外投入金额为 `600 × 2 = 1,200 元`。

执行方式含义：

- **单次**：同一回撤周期首次进入该档位时提醒一次；
- **分期**：按周分两期提醒，后一期仍需满足该回撤条件；
- **深度回撤每周**：持续处于该深度回撤区间时，每周最多提醒一次；默认最多 4 周且累计最多 4 倍基础金额。

修改策略后点击“保存计划”生效。

同一回撤周期会在价格恢复到固定 `cycle_peak` 的 98% 以上，且连续两个不同交易日的有效检查均满足条件后结束。同一天反复点击“立即检查”只累计一次；中间任何一个有效检查重新跌破该恢复线，恢复次数会重新计算。

持续补仓达到最大周数、累计倍数或金额上限后，基金卡片会显示 `PAUSED_FOR_REVIEW`。此时固定定投继续运行，但软件停止额外补仓提醒。只有你点击“确认继续补仓”后才会开放下一段有限额度；确认不会更换本轮 `cycle_peak`。

## 8. 30 日 K 线

在仪表盘基金卡片上点击“30日K线”或“查看详情”，即可加载最近 30 个交易日的 K 线。

- 红色：上涨；
- 绿色：下跌；
- 将鼠标移动到某根 K 线上，会显示该交易日的日期、开盘价、最高价、最低价、收盘价、涨跌额和涨跌幅；
- 十字线会跟随鼠标定位当前交易日。

K 线查询与主回撤计算相互独立。K 线暂时加载失败时，可以稍后重新打开详情，不会改变已有计划。

## 9. 策略历史

点击左侧“策略历史”，可以查看：

- 行情时间；
- 基金计划；
- 触发时回撤；
- 触发档位；
- 固定投入金额；
- 额外投入金额；
- 当前事件状态。

常见状态：

| 状态 | 含义 |
|---|---|
| `created` | 已创建，等待通知 |
| `notified` | 至少一个通知渠道发送成功 |
| `delivery_failed` | 通知发送失败 |
| `ignored` | 用户已忽略 |
| `postponed` | 用户已延后 |
| `expired` | 已不再满足继续提醒条件 |

选择一条历史记录后，可使用页面下方操作更新处理状态。

## 10. 邮件提醒配置

进入“系统设置”，在“SMTP 邮箱配置”中填写：

| 字段 | 说明 | QQ 邮箱常用示例 |
|---|---|---|
| SMTP 服务器 | 邮箱服务商提供的服务器地址 | `smtp.qq.com` |
| 端口 | SSL 连接端口 | `465` |
| 登录账号 | 用于登录 SMTP 的完整邮箱 | `你的QQ号@qq.com` |
| 邮箱授权码 | 邮箱服务商生成的 SMTP 授权码 | 不是 QQ 登录密码 |
| 发件地址 | 实际发送邮件的地址 | 通常与登录账号相同 |
| 收件地址 | 接收提醒的邮箱 | 可与发件地址相同 |
| 使用 SSL | 是否启用 SSL | QQ 邮箱端口 465 时勾选 |

配置流程：

1. 先在邮箱服务商设置中开启 SMTP 服务并生成授权码；
2. 在软件中填写以上字段；
3. 打开“邮件通知”开关；
4. 点击“保存并发送测试邮件”；
5. 收到测试邮件后，配置完成。

保存过授权码后，密码框会自动清空。再次修改其他字段时，密码框可以留空，软件会保留原授权码。

授权码保存在仅当前本机用户可读的应用数据文件中，不进入 SQLite 数据库，也不会包含在迁移包中。软件查询行情时不会要求输入 macOS 系统密码。

## 11. 桌面通知

在“系统设置”中打开“桌面系统通知”。首次收到通知前，请在 macOS“系统设置 → 通知”中允许 ETF Plan Assistant 发送通知。

邮件和桌面通知可以同时开启。任一渠道发送成功后，事件会记录为已通知，避免同一规则重复生成邮件。

## 12. 数据备份与恢复

### 12.1 导出迁移包

1. 进入“系统设置”；
2. 点击“导出迁移包”；
3. 选择保存位置；
4. 保存生成的 `.etfbak` 文件。

迁移包包含基金计划、策略版本、历史事件、通知状态和非敏感设置，不包含 SMTP 授权码。

### 12.2 恢复迁移包

1. 点击“恢复迁移包”；
2. 选择有效的 `.etfbak` 文件；
3. 等待校验和恢复完成；
4. 在新电脑上重新配置桌面通知权限和邮箱授权码。

恢复前软件会保留原数据库的回滚副本。不要手动修改 `.etfbak` 文件内容，否则完整性校验会失败。

## 13. 常见问题

### 13.1 点击立即检查后长时间没有更新

- 检查网络是否正常；
- 等待按钮从“后台抓取中”恢复；
- 不要连续重复点击；
- 若部分基金显示“历史行情暂不可用”，说明该基金当前历史行情源失败或数据安全校验未通过，软件不会用旧数据或异常数据触发提醒。

### 13.2 提示“行情检查正在进行”

上一轮查询尚未结束。等待完成即可。软件使用进程锁阻止多个检查同时写入，避免生成重复事件。

### 13.3 14:50 没有自动提醒

依次确认：

1. 当天是 A 股交易日；
2. 电脑在 14:45—15:00 保持唤醒并联网；
3. 基金对应的常规计划或回撤提醒已开启；
4. 桌面通知或邮件至少有一个渠道可用；
5. 同一档位在当前回撤周期内是否已经提醒过；
6. 顶部是否显示“定时检查：14:50 已启用”；
7. “上次检查”是否显示当天时间及成功状态。

### 13.4 邮件发送失败

- 确认填写的是 SMTP 授权码，不是邮箱登录密码；
- 确认 SMTP 服务已在邮箱网页中开启；
- QQ 邮箱通常使用 `smtp.qq.com`、端口 `465` 并勾选 SSL；
- 确认登录账号和发件地址相符；
- 重新点击“保存并发送测试邮件”。

### 13.5 K 线突然出现接近腰斩或翻倍

这通常来自 ETF 份额拆分、合并或行情源未复权。当前版本会优先使用前复权行情，并对备用数据进行折算检查。若软件无法确认调整比例，会拒绝使用该段历史数据计算提醒。

### 13.6 显示 `PAUSED_FOR_REVIEW`

表示该基金的持续补仓已经达到最大执行周数、累计倍数或金额上限。软件不会自动继续补仓。请先复核剩余资金和基金仓位；确认仍要继续时，在基金卡片点击“确认继续补仓”。确认后仍使用本轮原有固定高点，并重新开放一段有限预算。

## 14. 数据与安全说明

- 所有基金计划和提醒历史默认保存在本机 SQLite 数据库；
- 软件不会连接你的支付或证券交易账户；
- 软件不会自动交易；
- SMTP 授权码不会进入迁移包或 Git 仓库；
- 行情来自公开接口，接口短暂不可用时，软件会安全失败而不是使用可疑数据；
- 提醒仅用于执行你自己预设的计划，不构成投资建议，也不保证收益。
